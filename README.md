# Systems and media tooling

Work here focuses on the infrastructure and tools used for virtualization and media workflows.

## Areas

- **Proxmox VE** — custom and forked kernel, firmware, and QEMU packages, plus OpenZFS updates to support newer kernels
- **Media** — transport stream muxing, NDI recording, subtitle conversion, and Resolve-related utilities

These are primarily functional tools and patches. Issues and PRs are welcome for clear bugs or missing support on the configurations these projects target.
